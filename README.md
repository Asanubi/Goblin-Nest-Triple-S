# Goblin-Nest-Triple-S
Mods containing everything related to Triple S mod for Goblin Nest
An expansion mod for Goblin nest


# Features
3 new special characters
2 new base characters including its 3 variants
a new map for the expansion

# Note
While GNX still doesnt have a frame for making custom maps, only the special characters will be released as standalones for the moment until GNX gets updated to be able to make custom maps
